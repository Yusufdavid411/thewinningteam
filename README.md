# The Winning Team

A mobile-first personalized flyer generator for the FCSFUL Brothers Weekend.

## What it does

- Uses the supplied Brothers Weekend flyer as the fixed design.
- Lets a participant select a photo from their phone.
- Automatically fits the photo into the circular photo area.
- Lets the participant drag and zoom the photo until the face is positioned clearly.
- Generates the finished 1022×1536 flyer locally in the browser.
- Downloads the personalized flyer as a high-quality JPG.
- Does not upload participant photos to a server.

## GitHub Pages

The included workflow deploys the repository as a static GitHub Pages site whenever `master` is updated.
